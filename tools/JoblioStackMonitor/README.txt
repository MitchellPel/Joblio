Joblio Cloud Monitor v1.5.1
=========================

Everything for the server lives in this folder on the share:

  \\server\D\Joblio DB\Jobtracker\Joblio Cloud Monitor\

Files
-----
  Install Joblio Cloud Monitor (once).exe
      Run as Administrator — first time only.
      Creates desktop shortcut + starts with Windows.

  Open Joblio Cloud Monitor.cmd
      Use this every day after install (NOT the installer).

  README.txt
      This file.

After install
-------------
  • Desktop: "Joblio Cloud Monitor" (Joblio icon)
  • System tray: green / yellow / red dot on Joblio icon
  • Double-click tray icon to open dashboard

Do NOT run the installer daily — use Open Joblio Cloud Monitor.cmd
or the desktop shortcut.
